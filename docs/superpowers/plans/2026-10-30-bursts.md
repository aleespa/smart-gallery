# Bursts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bursts list in the Storage tab's right column. It groups shots taken within seconds of each other, using catalog metadata only. Each shot starts as keep. The user marks shots to remove, in a list view that expands per burst or in a large review view. Marked files go to the Recycle Bin through the existing `recycle` job.

**Architecture:** A no-Qt module `smart_gallery/storage/bursts.py` loads shots with one query, groups them, and resolves marks into files, as `storage/pairs.py` does for pairs. The Qt side adds `gui/storage/bursts_view.py` (list, expand grid, footer) and `gui/storage/burst_review.py` (one shot large, with a filmstrip). `gui/storage/view.py` gains a Pairs | Bursts switch, loads shots in its existing worker call, and reuses its `_on_move` to start the job.

**Tech Stack:** Python 3.13, PySide6, SQLite, pytest + pytest-qt (offscreen).

**Spec:** `docs/superpowers/specs/2026-10-30-bursts-design.md`. Read it with this plan. Copy and rules quoted here come from it.

## Global Constraints

- Grouping uses catalog metadata only (`taken_ts`, `camera`, `directory_rel`, name). Never read pixels, hashes or embeddings.
- Default gap **2 s**, adjustable **1–10 s** in whole seconds. Span cap **10 s**. Both are module constants.
- Every shot starts as **keep**. At least one shot of every burst always stays keep.
- Removal only through `recycle --list` as a job (`StorageView._on_move`). The GUI never writes the catalog or moves files.
- Reloads only ever drop marks. They never add one.
- No schema change and no migration. Read-only catalogs without `mirror_offloaded` must work.
- No-Qt/Qt split: `storage/bursts.py` imports no Qt. Colours come only from `smart_gallery/colors.py` or palette roles (`tests/unit/test_colors.py` rejects hex literals elsewhere).
- Format and lint only the files you touch: `uv run black <files>`, `uv run ruff check <files>`.
- Commit messages end with the session's attribution lines.

## Review Focus

1. **A catalog older than schema v7 (no `mirror_offloaded` table).** Bursts should still load. Test in Task 1: `test_load_shots_without_offloaded_table`.
2. **Answering "No" to the gap-change prompt.** The spin box goes back to the old value, and both the marks and the groups stay as they were. Test in Task 3: `test_gap_change_declined_restores_value`.
3. **A job finishing while the review view is open, removing the burst on screen.** The page goes back to the list without crashing. Test in Task 5: `test_review_closes_when_its_burst_vanishes`.
4. **Marks in folders outside the current scope.** They are still counted in the footer, which adds "(in k folders)", and they are still sent to the job. Test in Task 3: `test_footer_counts_marks_outside_scope`.
5. **Two cameras shooting in the same second, in the same folder.** They form separate bursts, never one interleaved burst. Test in Task 1: `test_cameras_interleaved_in_time_stay_apart`.

### Task 1: Shots and bursts (no Qt)

**Files:**
- Create: `smart_gallery/storage/bursts.py`
- Test: `tests/unit/test_storage_bursts.py`

**Interfaces:**
- Consumes: `storage.pairs.FileRef`, `storage.pairs.SIDECAR_EXT`, `storage.pairs.in_scope` (duck-typed on `.folder`, reused for bursts), and the `repo`/`make_item` fixtures.
- Produces:
  ```python
  DEFAULT_GAP = 2; MIN_GAP = 1; MAX_GAP = 10; SPAN_CAP = 10
  EDITED_SUFFIX = "-edited"
  ShotKey = tuple[str, str]  # (folder casefolded, stem casefolded)

  @dataclass(frozen=True)
  class Shot:
      folder: str; stem: str; taken_ts: int; camera: str | None
      files: tuple[FileRef, ...]      # candidate files, by relpath
      sidecar: FileRef | None
      shutter: str | None; aperture: float | None; iso: int | None  # first file's
      key: ShotKey (property); formats: str (property, e.g. "CR3+JPG")
      all_files: tuple[FileRef, ...] (property: files + sidecar)
      size_bytes: int (property, over all_files)

  @dataclass(frozen=True)
  class Burst:
      shots: tuple[Shot, ...]   # in time order, then relpath
      folder: str; key: ShotKey (first shot's); span: int (last - first ts)
      size_bytes: int

  def load_shots(repo: GalleryRepository) -> list[Shot]
  def group_bursts(shots: Sequence[Shot], gap: int = DEFAULT_GAP,
                   span_cap: int = SPAN_CAP) -> list[Burst]   # largest first
  def can_mark(burst: Burst, marks: AbstractSet[ShotKey], key: ShotKey) -> bool
  def burst_removals(shots: Iterable[Shot]) -> list[FileRef]  # by relpath casefold
  def reconcile_marks(old: Mapping[ShotKey, Shot], marks: AbstractSet[ShotKey],
                      bursts: Sequence[Burst]) -> tuple[set[ShotKey], int]
  ```

  - `test_span_cap_splits_chains`: 0, 2, 4, …, 14 at gap 2 give bursts covering 0–10 and 12–14 (cap 10 from the first shot).

  - `test_cameras_interleaved_in_time_stay_apart`: R8 at 0, 1, 2 and T6 at 0, 1, 2 in one folder give two bursts of 3, each with one camera.
  - `test_null_camera_is_its_own_value`: two NULL-camera shots 1 s apart give one burst. A NULL-camera shot next to an "R8" shot gives none.
  - `test_same_second_ordered_by_relpath`: `IMG_2.JPG` and `IMG_1.JPG`, both at ts 50, give shots in the order IMG_1, IMG_2.

  - `test_reconcile_drops_changed_and_orphaned_marks`: (a) a marked shot whose file mtime changed is dropped; (b) a marked shot that is now in no burst is dropped; (c) a burst whose every shot is marked loses all its marks; untouched marks stay. The returned count equals the number dropped.

- [ ] **Step 3: Implement `smart_gallery/storage/bursts.py`**

`load_shots`: one query selecting `id, relpath, ext, size_bytes, mtime_ns, media_type, taken_ts, camera, shutter_speed_text, aperture, iso` for `media_type = 'image' AND taken_ts IS NOT NULL`, plus a second query for `.xmp` rows. Read the offloaded set with `repo.offloaded_relpaths()` inside `try/except sqlite3.OperationalError` (missing table means an empty set), and compare casefolded. Group the rows by `(folder casefold, stem casefold)`, taking the folder from the POSIX parent of `relpath` as `pairs.py` does. Write a module docstring in the style of `pairs.py`'s.

`group_bursts`: sort the shots by `(folder.casefold(), camera or "", camera is None, taken_ts, files[0].relpath.casefold())`. Walk them in that order. A shot joins the current group when the folder and camera are equal, `0 <= ts - prev_ts <= gap`, and `ts - first_ts <= span_cap`. Drop single-shot groups. Sort the result by `(-len(shots), -size_bytes, shots[0].taken_ts)`.

`reconcile_marks`: implement the four spec rules (spec section "Removing", "Marks after any reload"). A shot is unchanged when `[(f.relpath, f.size_bytes, f.mtime_ns) for f in all_files]` is equal in `old` and the new shot.
